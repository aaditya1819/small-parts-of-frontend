# 90 Days HTML & CSS Challenge 🚀🎨

## 📌 About the Challenge
This repository documents my **90 Days HTML & CSS Challenge**, where I build **one small frontend project every day** using **pure HTML and CSS**.

The goal of this challenge is to:
- Strengthen my fundamentals
- Improve UI/UX thinking
- Practice real-world frontend components
- Build consistency through daily coding

Each folder in this repository represents a **small independent project** created as part of this challenge.

---

## 🎯 Challenge Goals
- Complete **90 small HTML & CSS projects**
- Improve layout, styling, and animation skills
- Learn by building real UI components
- Develop discipline and consistency
- Create a strong frontend practice portfolio

---

## 🧩 What This Repository Contains
- Login forms
- Hover animations
- Loaders & spinners
- Navigation bars & menus
- Buttons & UI components
- Cards & layout designs
- Small interactive UI effects
- Animation experiments using CSS

All projects are built using:
- ✅ HTML5  
- ✅ CSS3 (Flexbox, animations, transitions, effects)  
- ❌ No frameworks  
- ❌ No JavaScript (unless required minimally)
