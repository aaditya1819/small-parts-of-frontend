# 90 Days HTML & CSS Challenge 🚀🎨

Welcome to my **90 Days HTML & CSS Challenge** repository! This is a curated collection of small, independent frontend projects built daily to master the art of UI/UX design and CSS wizardry.

## 📊 Repository Stats
- **Total Projects**: 65+ 🏗️
- **Frameworks**: 0 (Pure Vanilla HTML/CSS) 🍦
- **Design Trends**: Neumorphism, Glassmorphism, Responsive Design, 3D Animations 🎨
- **Status**: 🟢 Active & Growing

## 📌 Project Overview
This repository is a journey through modern web styling, focusing on pure **HTML5** and **CSS3**. From trendy **Neumorphism** to complex **Animations**, each project is a standalone component ready to be explored and integrated.

### 🎯 Core Goals
- ⚡ **Strengthen Fundamentals**: Deep dive into CSS Flexbox, Grid, and Positioning.
- 🎨 **Visual Excellence**: Implementing high-quality, modern UI trends.
- 🔄 **Real-world Components**: Building reusable elements like forms, cards, and navbars.
- 🏗️ **Consistent Practice**: Daily coding to build discipline and a strong portfolio.
